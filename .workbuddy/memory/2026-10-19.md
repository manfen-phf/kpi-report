### 2. Tab 点击无反应 —— IIFE 作用域 bug（重要教训）
- **根因**：`showMainTab` 定义在 `(function(){...})()` 内部，而 HTML 写的是 `onclick="showMainTab(...)"`，
  inline handler 在**全局作用域**查找 → 找不到函数 → 点击静默失败（无报错，最难查的一类 bug）
- `setBiz` 当时恰好用 `window.setBiz = ...` 暴露了，所以那个按钮能用，掩盖了同类问题
- **修复**：删除所有 inline `onclick`，改为 JS 事件绑定
  ```js
  function bindTabs() {
    document.getElementById('mb1').onclick = e => showMainTab('tab1', e.currentTarget);
    document.getElementById('mb2').onclick = e => showMainTab('tab2', e.currentTarget);
    ...
  }
  ```
- 顺带：Tab 切换时 `history.replaceState` 同步 hash 为 `#tab1`/`#tab2`，并监听 `hashchange`
- **通用规则**：IIFE 封装时，若 HTML 里有 inline handler，必须显式 `window.xxx = xxx` 暴露，否则必踩坑
