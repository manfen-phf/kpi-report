## 修复 update.bat 双击部署失败（token 找不到）

**用户反馈**：双击 update.bat，报 `[ERROR] Deploy failed` + `ERROR: 未找到 GitHub token`

### 根因
`_deploy_api.py` 的 token 获取优先级：
1. 环境变量 GITHUB_TOKEN / GH_TOKEN
2. 同目录 `.github_token` 文件
3. `git credential fill`（GCM）

**第 3 种在双击场景失效**：GCM 凭据存在 Windows 凭据管理器，
`git credential fill` 在非交互环境（双击 cmd）经常取不到。
我在 Git Bash 里能取到（能看到 password=），但用户双击就取不到 —— **环境差异**。

### 修复
1. **已创建 `.github_token` 文件**（项目根目录），从 GCM 取 token 写入
   - 长度 40 字符，格式 `gho_...`（GitHub classic PAT）
   - **已被 .gitignore 排除**（第 5 行），已用 API 验证远端 404，密钥未泄露
2. `_deploy_api.py` 报错信息改为**可操作步骤**（生成 token → 建文件 → 粘 token → 重跑）
3. `update.bat`：
   - 启动时检测 `.github_token` 是否存在，缺失则给出提示
   - 部署失败时的提示改为引导用 token 文件方式
4. README 补上鉴权优先级表格 + 双击失败解法

### 顺带修复：bat 括号 bug
部署其实成功了（commit 4c853303f9），但末尾报 `into was unexpected at this time`。
原因：`if errorlevel 1 (...)` 块内的 echo 里有**未转义的半角括号** `(repo scope)`，
破坏了 cmd 的括号配对 → 解析到后面某行报错。
→ bat 规则补充：**`if` 块内的 echo 不要带半角括号**（用中文顿号或去掉）。

